# 🚌 Транспортный справочник

Консольное приложение на C++ для хранения базы данных остановок и автобусных маршрутов, обработки запросов к ней, визуализации карты маршрутов в SVG и построения оптимальных маршрутов поездки.

---

## 📋 Описание

Программа читает JSON-запросы на наполнение базы данных (остановки и автобусные маршруты), затем обрабатывает запросы к базе и возвращает ответы также в формате JSON. Дополнительно поддерживается отрисовка карты маршрутов в формате SVG и поиск кратчайшего пути между двумя остановками с учётом времени ожидания и скорости автобуса.

Проект создавался итеративно: от простого справочника с ручным вводом до полноценного приложения с JSON-интерфейсом, SVG-визуализацией и маршрутизацией. Логика чётко разделена на модули, чтобы каждый можно было развивать независимо.

---

## ✨ Возможности

📥 Чтение базы данных и запросов в формате JSON

🛑 Хранение информации об остановках (название, координаты)

🚌 Хранение информации об автобусных маршрутах (список остановок, тип маршрута — кольцевой или линейный)

📏 Расчёт длины маршрута, количества остановок и уникальных остановок

🔁 Расчёт коэффициента кривизны маршрута (curvature)

🗺️ Построение карты маршрутов в формате SVG с настройкой цветов, подписей и отступов

🧭 Поиск кратчайшего маршрута между двумя остановками (с учётом времени ожидания и скорости автобуса)

📤 Вывод ответов на запросы в формате JSON

## 🏗️ Архитектура

Проект построен по принципу разделения ответственности: каждый модуль решает одну задачу и не зависит от лишних соседей.

```
text
┌──────────────┐
│     main     │
└──────┬───────┘
       │
       ▼
┌──────────────┐    ┌───────────────┐    ┌──────────────┐
│ JSONReader   │───►│RequestHandler │───►│MapRenderer   │
└──────┬───────┘    └───────┬───────┘    └──────┬───────┘
       │                    │                   │
       │                    ▼                   ▼
       │            ┌───────────────┐    ┌──────────────┐
       │            │TransportRouter│    │     svg      │
       │            └───────┬───────┘    └──────────────┘
       │                    │
       ▼                    ▼
┌──────────────┐    ┌───────────────┐
│    json      │    │TransportCata- │
│ json_builder │    │    logue      │
└──────────────┘    └───────────────┘
```

### Ключевые модули

TransportCatalogue — хранит остановки и маршруты, умеет искать их по имени, считать статистику маршрута. Не занимается вводом-выводом.

RequestHandler — прослойка между каталогом, рендерером и роутером. Через него JSONReader получает всё необходимое.

JSONReader — читает входной JSON, наполняет каталог, формирует ответы.

MapRenderer — строит SVG-карту маршрутов по настройкам из render_settings.

TransportRouter — строит граф маршрутов и ищет кратчайший путь между остановками.

json / json_builder — собственная библиотека чтения и записи JSON.

svg — собственная библиотека генерации SVG-документов.

graph / router — шаблонный ориентированный граф и поиск кратчайших путей.
